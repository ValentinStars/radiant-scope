Linux · установка инструментов

Debian / Ubuntu:

sudo apt install iw network-manager tshark
sudo dpkg-reconfigure wireshark-common
sudo usermod -aG wireshark "$USER"

Arch Linux:

sudo pacman -S iw networkmanager wireshark-cli
sudo usermod -aG wireshark "$USER"

После добавления в группу войдите в сеанс заново. Приложение запускайте обычным пользователем. Права требуются только dumpcap.

Первый релиз **Radiant Scope** — локального Linux-монитора сети с русским интерфейсом.

### Внутри

- RSSI и история сигнала, RX/TX, packet rate, параметры Wi-Fi.
- TShark-захват: BPF, протоколы, поиск, детали, топ источников.
- Wi-Fi-окружение из NetworkManager, распределение по каналам.
- JSON/CSV-экспорт, адаптивный UI, настройки и demo mode.
- Работа без зависимостей Python, облака и внешних ресурсов приложения.

### Запуск

Скачайте `radiant-scope-1.0.0.pyz` и выполните:

```sh
python3 radiant-scope-1.0.0.pyz
```

Откройте http://127.0.0.1:8765. Требуются Linux и Python 3.10+. Для захвата установите TShark и настройте dumpcap; для Wi-Fi нужны iw и NetworkManager. Подробные команды — в README.

Проверка загрузки: `sha256sum -c SHA256SUMS`.

Для демо: `python3 radiant-scope-1.0.0.pyz --demo`.

### Проверено

12 автоматических тестов API и парсеров; реальный RSSI, захват и остановка пакетов, чтение AP-кэша; браузерные проверки desktop/mobile.

### Границы v1

История 600 измерений; пакетный буфер 2000, UI/JSON — последние 500. Snaplen 256 B, захват до часа. Нет полного payload/hex-декодера и PCAP-экспорта. Monitor mode зависит от адаптера/драйвера и может разорвать его Wi-Fi-соединение.
